This repository hosts my resumes, written in LaTeX. Each resume lives in its own folder with an English ([resume-en.tex](dotnet/resume-en.tex)) and a Russian ([resume-ru.tex](dotnet/resume-ru.tex)) version:

- [dotnet/](dotnet/) -- .NET developer resume
- [python/](python/) -- Python developer resume (template, experience not yet filled in)

Shared packages and macros are in [resume-common.tex](resume-common.tex). Build everything with `make build`, or a single resume with `make dotnet` / `make python`.

## Contributing

As this is my personal resume, I'm not accepting contributions. However, feel free to use the LaTeX source code as a reference for your own resume.
